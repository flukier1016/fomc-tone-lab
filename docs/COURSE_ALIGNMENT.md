# Course connections and local model training

The integrated presentation follows five questions: what information is available, how tone is measured,
whether it relates to yields, whether a delayed duration trade works, and what the evidence permits us to conclude.
Its contents page is generated from the slides that are actually present, including when a sparse store omits a result.

## What the local fine-tuning actually did

The saved record is `data/baselines/roberta-tuned.json`; the implementation is `src/fomc/finetune.py`.
The record reports PyTorch's Apple `mps` device. This is full-parameter supervised fine-tuning of a pretrained
RoBERTa encoder with a three-class head, using public expert labels rather than labels generated by Claude.

1. Keep the Trillion Dollar Words split fixed: 1,984 training sentences and 496 held-out test sentences,
   with the same training data used by the TF-IDF and embedding baselines. The saved record retains sentence hashes.
2. Compare nine configurations: four learning rates for RoBERTa-base, three for RoBERTa-large, and two refinements.
   Each uses the same five stratified folds. Mean validation macro-F1 selects both the configuration and the epoch.
3. Use class-balanced cross-entropy, AdamW, 10% warmup, linear learning-rate decay and gradient clipping.
   The selected setting is RoBERTa-large, learning rate 2e-5, batch 16, maximum length 256, stopping at epoch 9
   of the ten-epoch schedule. Its stored validation macro-F1 is 0.7242.
4. Refit that fixed setting on all training sentences with seeds 0-4. Average class probabilities before evaluating
   the ensemble on the held-out test. The resulting macro-F1 is 0.737, compared with Claude's 0.661.
5. For each Fed document, average `P(hawkish) - P(dovish)` over its sentences. Store the document scores, model
   revision, test probabilities and search history so the comparison can be inspected without retraining.

The local weights are retained in the ignored `data/processed/roberta-tuned/` directory. The submission includes
the saved predictions and provenance, allowing the reported comparison to be reproduced without training or an API key.

This reference was added after the original results. It does not redefine H1, replace Claude in the frozen event study
or backtest, or establish trading alpha. Public expert labels may have appeared in prior model training. The independent
post-cutoff human test remains unrun. No model was retrained and no research estimate was recomputed for this presentation edit.
